# ESS HOD CUP 2026

Official website of the ESS HOD CUP 2026, the Estate Security Service inter-department football tournament.

Pages: Home (countdown, match of the day, results, upcoming matches, table, top scorers), Fixtures (search, filter, PDF download), Results, Standings, Teams, Players and Top scorers.
It works on phones and computers, and has a light/dark mode.

The standings, top scorers and tournament statistics are calculated automatically from the scores in `data.js`.

## Files

All files sit together in one folder, with no subfolders.
